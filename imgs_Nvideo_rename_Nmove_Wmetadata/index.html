Renombrado y Organización de Imágenes y Videos

Este proyecto permite renombrar y mover archivos de imagen y video utilizando metadatos como la fecha de modificación, ubicación, etc. Se utiliza Python junto con librerías como pillow-heif, exiftool y ffmpeg.

Características

  • Soporte para imágenes HEIC, JPG, PNG.
  • Extracción de fechas usando metadatos reales.
  • Geolocalización con OpenCage API.
  • Organización automática por carpetas según fecha y lugar.
